# Rubik's Cube Solver AI — Final Report

All numbers below are read directly from `benchmarks/basic.json` and `benchmarks/with_dataset.json`, produced by `benchmark.py`.

## Setup

- Architecture (both runs): `[324, 256, 256, 18]` — same network, same hyperparameters. Only the training data changed.
- Baseline (8k generated scrambles, lengths 1-6): Baseline: 8k generated scrambles, 5 epochs.
- With dataset (120k generated scrambles, lengths 1-6): Larger dataset: 120k scrambles, 12 epochs.
- Evaluation (identical for both): 400 fresh scrambles per length for move accuracy (lengths 1–8), 40 greedy solves per length for end-to-end solving (lengths 1–6), fixed seed 424242.

## Findings

- Both models are perfect on single-move scrambles (100.0%). The task is easy there.
- The dataset is the whole difference: 15x more training samples (8k → 120k) at the same architecture lifted 4-move accuracy 54.5% → 84.2% (+29.8 pp).
- End-to-end solving improved most on medium scrambles: 3-move success 80.0% → 100.0%, 6-move success 5.0% → 52.5%.
- Average moves to solve drop sharply, so the improved model wastes far fewer actions before reaching a solved state.
- Longer scrambles (7–8 moves) remain weak because the network was only trained on scrambles of length 1–6; accuracy there is extrapolation.

## Honest limitations

- This is not a general Rubik's cube solver. It learned to invert short scramble sequences from states seen in training distribution; it will not solve a random 40-move scramble like a Kociemba/CFOP solver.
- The greedy loop can loop forever on a wrong move (capped at 40 steps in the benchmark); success rate counts only states actually solved.
- No search or backtracking is used — the model commits to its top prediction at each step. Adding beam search or a learned value function is the next step.
- Data is synthetic and generated by this repo's own cube simulator; the self-test in `cube.py` verifies all 18 move permutations and their inverses.

## Reproduce

```bash
python3 cube.py
python3 train.py --samples 8000 --epochs 5 --out models/model_basic.npz
python3 benchmark.py --model models/model_basic.npz --out benchmarks/basic.json --label baseline --dataset '8k generated scrambles, lengths 1-6'
python3 make_dataset.py --samples 120000 --out data/cube_dataset.npz
python3 train.py --dataset data/cube_dataset.npz --epochs 12 --out models/model_dataset.npz
python3 benchmark.py --model models/model_dataset.npz --out benchmarks/with_dataset.json --label 'larger dataset' --dataset '120k generated scrambles, lengths 1-6'
python3 make_report.py
```
